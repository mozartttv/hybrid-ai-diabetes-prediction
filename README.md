# hybrid-ai-diabetes-prediction
## Overview
This project evaluates hybrid artificial intelligence models for predicting diabetes using the Pima Indians Diabetes Dataset. The study compares traditional neural network models with hybrid models incorporating fuzzy inference systems, symbolic reasoning and genetic algorithm optimization.

## Dataset
The dataset used is the Pima Indians Diabetes Dataset, containing diagnostic health measurements such as glucose levels, blood pressure, BMI, and age.

## Models Implemented
1. Neural Network
2. Logical Neural Network
3. Adaptive Neuro-Fuzzy Inference System (ANFIS)
4. Genetic Algorithm Optimized Neural Network
5. Genetic Algorithm Optimized Logical Neural Network
6. Genetic Algorithm Optimized ANFIS

## Methodology
1. Data preprocessing and normalization
2. Model training and validation
3. Genetic algorithm optimization of model parameters
4. Performance evaluation using classification metrics

## Evaluation Metrics
- Accuracy
- F1 Score
- Interpretability

## Results
Hybrid models optimized with genetic algorithms(LNN especially) demonstrated improved prediction performance compared to baseline models.
